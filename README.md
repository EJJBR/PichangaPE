# PichangaPE ⚽📱
**La solución inteligente para la gestión y reserva de complejos deportivos.**

PichangaPE es una aplicación móvil nativa diseñada para digitalizar el negocio del alquiler de canchas. El proyecto resuelve la desconexión entre dueños de locales y deportistas, ofreciendo un ecosistema seguro para gestionar horarios, pagos y reservas en tiempo real.

---

## 🌟 Experiencia del Usuario (UX)

La aplicación está dividida en dos módulos especializados según el rol del usuario:

### 🏁 Para el Propietario (Gestión de Negocio)
*   **Panel Administrativo:** Control total sobre sus canchas (Crear, Editar, Listar).
*   **Inteligencia de Negocio:** Dashboard con estadísticas de ingresos reales y volumen de reservas.
*   **Verificación de Pagos:** Herramienta interactiva para visualizar vouchers de pago mediante zoom y aprobar/rechazar solicitudes al instante.
*   **Reportes PDF:** Generación automática de documentos profesionales con el historial de uso de cada cancha, ideal para cierres de caja.

### 🏃 Para el Cliente (Reserva Rápida)
*   **Catálogo Interactivo:** Buscador con filtrado inteligente por nombre o ubicación.
*   **Reserva Guiada:** Sistema que restringe fechas y horas según la disponibilidad real configurada por el dueño, eliminando errores de doble reserva.
*   **Pago Digital:** Integración transparente para subir comprobantes de pago (Yape/Transferencia) directamente desde la galería.
*   **Seguimiento:** Historial personal para monitorear el estado de sus reservas en tiempo real.

## 🛠️ Stack Tecnológico y Desafíos Técnicos

Este proyecto demuestra mi dominio en el ciclo completo de desarrollo:

*   **Android Nativo (Java):** Implementación de arquitecturas basadas en Actividades y Adaptadores personalizados.
*   **Backend RESTful (PHP):** Creación de una API personalizada para la comunicación eficiente entre la app y el servidor.
*   **Base de Datos Relacional (MySQL):** Diseño de un modelo entidad-relación robusto para gestionar usuarios, canchas y transacciones.
*   **Integración de Nube (ImgBB API):** Implementación de almacenamiento externo de imágenes para optimizar el rendimiento del servidor principal.
*   **Librerías de Alto Nivel:**
    *   **Volley:** Manejo de peticiones de red asíncronas.
    *   **Glide:** Procesamiento y visualización eficiente de imágenes.
    *   **PdfDocument:** Ingeniería de software para generar reportes físicos desde código móvil.

## 🚀 Potencialidades del Proyecto

PichangaPE ha sido construida pensando en la **escalabilidad**:
1.  **Modelo Multi-Dueño:** Estructura preparada para convertirse en un marketplace regional.
2.  **Arquitectura Ligera:** Gracias a la gestión de imágenes en la nube, la app mantiene un rendimiento fluido incluso con cientos de registros.
3.  **Extensibilidad:** Código preparado para futuras integraciones como pasarelas de pago directo (Stripe/PayPal) y notificaciones Push.
